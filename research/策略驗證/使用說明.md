# Stock Terminal 離線策略驗證

本原型供人工研究使用。使用者的券商沒有可用 API，因此本工作的價值在於比較策略假設、成本與樣本外表現；不包含券商串接、自動交易或部位同步，也沒有替換 WaveDeck。

## 已完成的範圍

- 唯讀擷取 ST `data/market.db` 的日線，保留輸入快照與 SHA-256；可直接重播快照。
- 固定 20／60 日均線交叉，收盤計算訊號、隔日開盤模擬成交；只做多或空手，不借款、不放空。
- 全額資金、允許分數股；買進成本以可用現金反推可買股數，賣出成本扣除後回到現金。期末持股按收盤估值，不虛構最後一天已完成平倉。
- 買進／賣出總成本預設 25／55 基點，作為未核實的費用及滑價壓力假設。不是使用者券商報價，也不是交易稅規則。
- 對照獨立現金／股數帳本，另用 Node.js 執行 ST 4.0.2 JavaScript 回測核心，核對相同隔日開盤與成本下的逐筆交易、每日權益、最大回撤及未平倉狀態；不再使用已淘汰的同收盤價成交假設。
- 固定 25 組均線參數，檢查 3×3 鄰域的穩健區；沒有看過結果後擴大範圍。
- 滾動樣本外驗證：訓練 1,095 個日曆日、測試 180 個日曆日、每個訓練窗口暖機 80 根。附相同樣本外期間的固定參數與買進持有比較。
- 全部 25 組參數各作 3 次歷史截短檢查，驗證歷史訊號不受後續價格影響。
- 附上游 MCPT 診斷，保留其口徑限制；零交易或無效分布顯示「無有效檢驗」，不輸出虛假的零 p 值。

## 執行方式

使用 ST `data/stock_python.path` 指定的 Python，以及已安裝的 NumPy、pandas、Matplotlib。這些依賴只在研究程序使用；沒有增加 ST 主伺服器的啟動依賴，也不會自動安裝套件。

驗證版本固定在根目錄 `requirements-research.txt`；需要時由使用者自行對選定的 Python 執行 `-m pip install -r requirements-research.txt`。獨立 Linux／Windows 研究 CI 會安裝並完整測試；一般核心 CI 未安裝研究依賴時明確略過研究類別。

從專案根目錄執行：

```powershell
& .\research\策略驗證\開始離線驗證.ps1
```

Node.js 不在 PATH 時，加入 `-NodePath` 指定既有執行檔。每次輸出均位於新的 `scratch\離線策略驗證-時間戳` 子目錄，既有結果不覆寫。開啟其中的 `研究報告.html` 即可閱讀；報告不依賴網路或執行中的 ST 服務。

進階重播（先執行 Python，再核對既有核心）：

```powershell
$研究Python = (Get-Content .\data\stock_python.path -Raw).Trim()
& $研究Python -E -B -X utf8 .\research\策略驗證\離線驗證.py --快照 '既有結果目錄\輸入快照.json' --輸出 '.\scratch\離線策略重播'
node .\research\策略驗證\核對既有核心.js '.\scratch\離線策略重播'
```

`--買進基點`、`--賣出基點` 可指定研究成本，`--標的` 可指定已有至少 400 筆本機日線的台股。完整的 1,095／180 日樣本外流程需要更長的資料；不足時明確失敗，不會縮短窗口湊出結果，也不會連網補資料。重播沿用快照的標的與日期。

## 上游採用與修正

來源為 Blave-TW/blave-agent，固定 commit `eea03f1a50d034fff778a381bc2a91e61eaf1dd0`。`上游來源.json` 保存逐檔雜湊，執行前逐一驗證。Apache-2.0 的 LICENSE 與 NOTICE 原樣保留。

只納入 `analysis`、`param_scan`、`walk_forward`、`validation`、`progress`；未納入上游資料下載、憑證、通知、runner、券商、交易管理與桌面外殼。程式呼叫前安裝程序稽核攔截，拒絕 socket 連線與外部程序；這是防誤觸措施，不取代平台沙箱。

上游原始檔不修改，研究程序內明確替換兩個計算介面：

1. **損益**：上游 `precise_pnl` 將隔夜與日內報酬直接相加；100→110→121 的完整持股範例會得到 20%，實際價格比率是 21%。轉接層以進場／持有／出場三種情境計算複利與不對稱成本，並以獨立現金帳本核對。
2. **績效統計**：最大回撤納入初始權益 1，避免首筆虧損消失；研究年化以資料實際日期跨度與密度計算，與 ST 固定 252 日夏普口徑不同，不比較兩者夏普數字。只支援明確的日線做多／空手模型，其他曝險或同根收盤成交會拒絕。

跨核心對照把每邊研究總成本填入 ST 的費用欄、額外滑價設為零，避免重複計費。零成交量資料明確拒絕，不假設停牌時可成交；缺失日線與真實交易日曆仍是資料限制。

上游 `wf.json` 的 `fee` 為介面需要的對稱平均值；同檔加註實際買進／賣出成本及轉接說明，避免誤認為損益採對稱費率。

MCPT 本身使用固定部位、收盤至收盤報酬置換、對稱平均成本；與隔日開盤和不對稱成本的主研究不同。其 p 值只列附加診斷，不作策略顯著性或升級依據，更不是未來獲利機率。

## 研究限制與權限

本機日線庫沒有逐列來源、歷史發布版本或還原契約，不能把目前快照視為完整時點資料。沒有股息現金流、整股及最低手續費、漲跌停、成交量限制或停牌處理；真實費率也未核實。報告首頁保留這些限制。

ST 既有 Promotion Gate 只評估研究證據，未提供不存在的失效監控，因此維持 `FAIL`、`autoPromote=false`。樣本數以樣本外日線計算，明示不等同獨立交易筆數。任何結果都不寫入 DecisionContext、曝險限制或 WaveDeck。

這是獨立離線研究工具，程式納入儲存庫，研究輸出留在忽略追蹤的 `scratch`；不掛入 ST 主介面或一般分享包。程式不呼叫外部行情、模型與券商 API。若日後製作自動交易能力，需另行界定需求，不能當作本工具的驗收標準。
