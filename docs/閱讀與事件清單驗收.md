# 閱讀與事件清單

盤後頁更新保留表格排序、水平及垂直位置、展開狀態與焦點。單一來源更新失敗時使用最後成功資料，顯示嘗試時間、最後成功時間與來源時間；來源沒有時間時明確標示未提供。個股期合約、資金流子項與漲跌排行分別保留缺漏項目。

各區可開啟全寬對話框，返回時回到原區與原閱讀位置。手機原有兩欄總覽與完整欄位保留。對話框支援返回按鈕與 Escape；瀏覽器原生焦點限制避免鍵盤落到背景。

自選股體檢第一批讀取最多 40 檔。「載入其餘」依序讀取剩餘批次；失敗項目可重試。總數、成功、失敗／資料不足與待載入數量分開顯示，完整總表保留全部代號，包括尚未載入及失敗項目。批次端點使用 `cacheOnly=1`，不因讀取新清單而下載外部行情。

事件分為新成立、持續追蹤、已失效及資料不足；分類使用既有個股訊號引擎回傳的生命週期。成立日、狀態日、證據日期、依據、失效條件及成立日參考值並列；移動均線參考值不當作目前失效距離。事件從目前歷史快照重建；不冒稱首次觀測紀錄。可開啟圖表體檢與既有 ETF 明細，ETF 仍使用自身比較日期。

進階與專業體檢在成績單旁提供「歷史研究與真實前瞻對照」。擁有者端點 `/stock-signals/research/status?comparison=1` 唯讀檢視原有每日帳本，沒有另一個事件寫入者。5／20 日成熟結果由凍結價格、日期與雜湊核對；無結果就等待，無法核對者另計。規則版本各自統計，歷史結果須具相符規則與方法指紋才在此顯示比率。

報酬統一採下一交易日收盤進入，並提供 0／20／50／100 基點往返成本假設。相對基準是同股票、同大盤情境、在事件前已成熟的過去結果，並非持有期間的大盤超額報酬。歷史研究有 5 根間隔，真實帳本保留每日事件，兩者不是完全相同的抽樣集合。至少 20 筆僅允許描述統計，不代表通過優勢檢定或自動晉升候選。
