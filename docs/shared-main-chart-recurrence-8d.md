## 結論

兩份 8D 是**同一個共用主圖流程**的兩次發作，不是兩個獨立問題：

1. **主圖標頭、下方行情列、報價端點各自決定「參考價」與「當前報價」**，沒有共用一份契約。大盤那次表現為昨收來源不同（Yahoo 49302.00 對官方 48341.31）；台指期這次表現為期間標籤與資料粒度錯配、日盤時段拿到前一晚夜盤。
2. **測試環境與正式頁面不一樣，遮住了缺陷。** 既有測試自行建立 `window.S`，而正式頁面的 `S` 是頂層 `let S`，`window.S` 為 undefined。大盤 8D 的前端案例就有這個問題（8D 報告 2026-10-16 更正段已承認）。
3. **前一次 8D 結案範圍不足**：大盤 8D 沒有把同一條主圖流程上的台指期納入，所以相同缺陷在台指期重發。

因此合併處理有實益：共同根因、共同的流出根因與共同的防再發措施，只需要寫一次、驗一次。
