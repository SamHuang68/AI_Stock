# PDF 匯出可靠性

本輪接續架構審查的外部依賴與非同步工作整理。既有計畫匯出使用 jsPDF 2.5.1；隔離重現另發現長報告需要 14 頁時只輸出 11 頁，仍回報下載成功，且相鄰頁內容重疊。載入失敗後的 Promise 永久快取、來源無期限等待、渲染失敗殘留容器、並行匯出及尚未完成下載就回報成功亦有對應重現。

## 固定依賴與來源

jsPDF 升級至 4.2.1，html2canvas 維持 1.4.1；兩者改為首次匯出時載入同源資產。官方 npm 套件先驗證 SHA-512，再只取瀏覽器檔及 LICENSE。各版本目錄的 `來源資訊.json` 保存下載來源、套件完整性與逐檔 SHA-256；Git 屬性保留原始位元組，避免 Windows 換行轉換破壞證據。

官方 jsPDF 4.2.1 發行說明列出 HTML 輸出與註解物件注入修正。本專案的匯出路徑只使用 JPEG、分頁與儲存，沒有直接使用公告中的輸出選項或註解 API；因此這次是移除過舊依賴並驗證相容性，不宣稱已證實公告弱點可透過目前匯出流程觸發。計畫文字在進入 HTML 前仍需完整跳脫。

Private Web 及分享包必要檔案清單包含兩套資產、授權與來源資訊。分享包掃描中的 jsPDF 官方公開作者署名只對精確路徑及固定 SHA-256 放行郵件格式規則；換路徑、改檔或偽造來源資訊不能取得例外，其他秘密資料規則仍照常執行。

獨立審查另發現非 UTF-8 改檔會被文字掃描略過。現在固定官方例外路徑先核對原始位元組，雜湊不符直接回報 `vendor-integrity`，無法解碼也不能繞過；其他既有文字編碼策略維持原樣。

## 匯出契約與能力範圍

同時只執行一個匯出工作，開始時複製計畫；來源後續修改不會混入同一份報告。依賴載入最長 15 秒，失敗可重試且核對 jsPDF API 與版本。基本面最多四路並行，單筆 8 秒、整批 30 秒；缺值與原因明示，計畫仍完整保留。報告產生日期採臺灣時間，不冒充來源觀測日期，公司名稱不再只取前十二字。

先依實際 DOM 高度完成分頁，再逐頁轉為畫布。表格重複欄頭，排序編號跨頁接續，標題與下一個內容單位一起換頁。最多 120 頁；單一不可拆的表格列、清單項或報告區塊超過一頁時，整次匯出明確失敗，不下載截斷檔。

暫存內容使用獨立 iframe，成功或失敗都清理遮罩、文件與畫布；渲染逾時後晚到的畫布也會釋放。字型等待最長 10 秒、單頁渲染 20 秒、整份渲染 120 秒、儲存等待 20 秒。逾時表示未確認完成，不能據此宣稱所有底層工作或瀏覽器下載均已取消。

預設等待 jsPDF 儲存 Promise 完成，結果只表示已交由瀏覽器下載，不宣稱已驗證使用者磁碟寫入。`generate({save})` 可接受非同步儲存介面，方便應用程式接到其他儲存目的地。PDF 沿用畫布影像格式，沒有新增文字搜尋、OCR 或匯入往返保證；Chromium 驗證不代表 Safari／iOS 已驗收。

## 驗收方式

行為測試使用正式匯出模組與可控制的 DOM、來源回應、canvas 及下載完成時機，覆蓋重試、期限、並行工作、計畫副本、錯誤清理與內容完整性。資產測試核對原始位元組、實際 HTTP、Owner／Reader 靜態讀取、分享包複製及 ZIP 內容。瀏覽器以隔離計畫及固定基本面產生一般、超過十一頁的測試報告，另外渲染產生的 PDF 核對頁面。

本文件描述變更契約；測試數量、實檔頁數、精確提交、CI 與雙端部署證據以本輪交付紀錄為準。既有正式計畫、行情資料、外部通知及 AI 供應商設定不由這些測試修改。
