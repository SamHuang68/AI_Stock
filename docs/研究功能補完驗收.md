## 資料與權限

研究查詢只使用既有本機資料與已載入快取，不觸發 Yahoo、官方全市場下載或新的模型呼叫。`POST /screen3` 的 `research.enabled=true` 在一般選股下載流程之前分流。

`GET /valuation-research/{symbol}`、`GET /breakout-research` 及固定標的 `GET /research/portfolio` 為市場研究唯讀資訊。私人快照、個人標的研究、預警帳本與影子紀錄僅限擁有者；保存影子紀錄使用擁有者的 `POST /breakout-shadow` 及既有同來源檢查。所有入口維持 Tailscale 私有 gateway，沒有新憑證或公開 HTTP 服務。

查詢拒絕未知、重複及空白參數，日期保持明確截止日。沒有本機分類時不退回連外查詢；資料不足和讀取失敗有明確狀態。個股與 ETF 的公司行動涵蓋分開判斷。

估值頁的讀者模式僅提供暫時計算，不讀寫擁有者的瀏覽器假設、草稿及歷史；權限降低時清除畫面中的私人副本，保留原始儲存資料。研究工作台遇到損毀草稿或外部更新衝突時保留原字串，並將本頁輸入另存於完整備份，避免切頁或重新載入覆寫資料。

## 可重現驗證

新增 Python fixtures 驗證來源與日期、成交時序、成本、每日資產曲線、固定樣本外時間切分、缺日與不可成交、首次保存、預警版本及 HTTP 權限。Node 測試執行實際前端模組，驗證排序、草稿與損毀儲存、引用約束、取消與路由變動。瀏覽器測試覆蓋窄螢幕、橫向、桌機、縮放與反覆切頁；CI 在 Windows／Linux 各跑完整 Python、JavaScript、離線研究及瀏覽器檢查。

發布只使用精確合併 SHA、通過全部 CI 的封存內容。停止已驗證身分的正式寫入者後，完整備份所有 SQLite 資料庫，核對完整性、schema 與逐表內容；程式切換前後保持既有資料，再驗證實際正式 SHA、私有 HTTPS 及 UI。

## 尚不能由工程測試代替的證據

缺少歷史當時可得財報、完整下市全集、股息與分割持有權利時，不宣稱完成點時回測、總報酬或消除存活者偏差。官方參考因子與原始成交研究保持分開。

新啟用的每日個股觀察，需要真實後續交易日才能形成 5／20 日成果；不回填或縮短持有期。歷史預警觀測若缺少可核對程式摘要，保留原資料並回報版本不可重播，不冒稱新規則可重現舊規則。

研究任務只有在目的地、供應商及模型可核對時才允許送出；僅能確認 CLI 名稱而無法確認最終端點的模式不視為目的地已驗證。普通副駕仍遵循原有路由及資料約束。
