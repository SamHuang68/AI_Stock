# 資料研究與局部穩定性收尾

本輪在既有 4.0.2 回測與 0–100 技術分數之上，增加選定快取更新與官方日線研究。完整來源、版本、備份、取消與樣本限制見 [K 線事件研究](K線事件研究.md)。體檢仍獨立於技術分數，DecisionContext 與 AI 證據約束沿用現行契約。

## 台指期分時

圖表工具的「台指期分時」與 `GET /txf-intraday` 使用既有 Yahoo 台灣 `WTX&` 頁面。2026-10-02 實際回應有專屬 `MarketChartStore/libra/WTX&` 節點、`TFE`、`Asia/Taipei`、`1m`、來源時間與 `sourceTradingPeriods`，取得 377 根有收盤值的分鐘資料。測試只節錄少量公開數字與 metadata；不以頁面其他股票的第一個 timestamp 陣列充當來源。

解析器不執行網頁程式；核對標的、時區、盤別起訖、時間順序與 OHLCV 長度。未來空列排除，價格缺值不造 K，未知成交量保留 null，來源缺前收不以首筆價格補造。不同來源區段與缺分鐘不連線；來源時間超過 15 分鐘顯示較舊，並不推定此時市場開盤。

開啟或按重新取得才呼叫來源，60 秒內沿用記憶體快取，不自動輪詢；單次上限 15 秒、2 MB。失敗明示無法核實，絕不回退到日線或以即時報價合成分鐘 K。近一連續行情不是指定月份合約；不寫入日線庫，不供回測，不改主日線、FinMind 日盤、Pulse 盤別或夜盤顯示。

## 本機語音與診斷寫入

AI 摘要朗讀不再截斷前 120 字，而以每段最多 120 個 Unicode code point 播放完整本文。只接受瀏覽器明示 `localService===true` 的中文 voice，優先臺灣中文；沒有本機語音時提示，沒有外部音訊服務。停止、重啟及錯誤都終止本輪佇列，舊 callback 不能重新播放。實際音質與可用語音仍取決於作業系統；離線測試使用 mock，不發出音訊。

既有五個 JSONL 診斷寫入路徑共用路徑鎖，將追加與縮檔包在同一臨界區；Windows 暫時共用違規沿用 atomic_store 的有界重試。DecisionContext 與 early-warning 歷史庫採 WAL，測試先重現 DELETE journal 的讀取交易阻擋提交，再驗證新觀測可提交而既有讀取快照保持固定。未改計算或事件內容。

Claude 透過既有登入做一次有限程式覆核，並受委派產出語音修正與測試。主實作者另外檢查並修正取消例外、測試語法及跨 VM 陣列斷言，再執行測試；不是把未執行的模型回覆當作驗證。沒有傳送憑證或正式資料、啟用額外額度或建立新服務。
