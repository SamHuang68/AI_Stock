此變更以 c8274eb4995cc07a90bb6b5414b5dc81a919f273 為基底，修正三項定向評估確認的 P2 問題。型態偵測公式、0–100 技術分數與獨立體檢的研究算法維持原有定義。

沿用共用 showProModal，新增可選 owner／onClose 及回傳 modal 元素。舊單參數用法不變。關閉、取代與新圖載入使舊請求失效；AbortController 取消 fetch，回覆本文仍需再次核對取消狀態，避免不遵守取消的來源寫入快取。統計分批計算也在失去歸屬時停止。

獨立的型態歷史統計仍顯示實際樣本與上漲比例，保留樣本不足、重複計數及未還原除權息限制。規則描述不當成獲利機率，也沒有為文案新增策略排名或資料抓取。

## 美股日曆

server/us_equity_calendar.json 為本機已核對參考，版本 us-equity-sessions-1、核對日期 2026-10-03，涵蓋 2026-01-01 至 2028-12-31。來源為 [NYSE 交易時間公告](https://www.nyse.com/trade/hours-calendars)，2026 年另以 [Nasdaq 公告](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule) 交叉核對。

適用美國股票／ETF 核心交易時段的共同日曆參考；不適用期貨、債券、選擇權或延長交易。臨時休市需依交易所新公告更新，不能把有限年度資料當成永久日曆。

- 使用 America/New_York 時區處理夏令時間，一般核心時段 09:30–16:00。
- 半日收盤採公告 13:00，沿用既有 30 分鐘收盤確認期，因此 13:30 起視為最終日線。既有 sessionOpen 欄位包含這段確認期，不能解讀為可成交狀態。
- 2026-12-25 休市，最近應有日線為 12-24；2026-12-24 14:00 美東不再標為盤中暫定。
- 2028 元旦落在週六，不自行把 2027-12-31 推算為補假。
- 未涵蓋年度或時區資料缺失時，expectedLastDate 為 null，新鮮度未知；當日來源列維持暫定，不當成最終值寫回。
- 行情載入與資料品質評估共用同一收盤截止時刻；已知休市的來源列不新增至日線庫。既有歷史資料不清除、不遷移。
- 既有 session API 加入 calendar 的版本、來源、涵蓋期間、狀態與時段；原有 provisional／note 保留。使用自訂 bars_loader 而沒有新 session metadata 的呼叫者仍相容。
- 台股沿用原本官方交易參考與來源日期規則。

後續更新：只依官方已公告年份修改 JSON、更新核對日期及版本，並補已知休市／補假／半日／跨年案例。未確認年份持續 unknown，不使用公式或星期幾替代官方已核對資料。

## 定向驗證

Python：tests/test_us_equity_calendar.py 共 10 案例，包含固定時鐘、無補抓、未知日線不入庫、假日來源不入庫、品質截止時間及 API metadata。加上既有 3 個相鄰案例，確認台股盤中／休市／未知日曆行為。

~~~powershell
python -B -m unittest tests.test_us_equity_calendar -v
npm run test:pattern-browser
~~~

實際工作環境使用絕對路徑 Python，且可透過 ST_PLAYWRIGHT 指向已安裝的固定版本；不要求另行安裝瀏覽器。ST_BROWSER_OUTPUT 可指定報告與截圖目錄。

tests/pattern_modal_browser.cjs 使用產品型態模組及原有 modal 函式，11 個 Chromium 案例涵蓋亂序、關閉、重開、跨市場、圖表序號、其他工具、HTTP 失敗、本文延遲、取消、文字及停止批次。包含一個手機尺寸關閉案例；沒有聲稱實機、Safari 或正式行情驗證。全程固定資料，實際網路請求為零。

新瀏覽器指令已接入既有 CI，日曆 Python 案例由原有 unittest discover 收集。新日曆 Python／JSON 同時列入分享包與私有發布必要檔案 gate。本輪只做本機定向驗證，尚未推送、執行 CI、合併或部署。
