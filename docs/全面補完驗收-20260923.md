# 歷史階段補齊與研究工作流驗收

本輪承接 2026-09-08 全面升級計畫的 S1–S6，以及 9/22 文章研究第三階段後的工程缺口。舊全面升級 S2 與文章研究第二階段是不同工作；本輪逐項承接行為，沒有直接合入未發布的舊提交覆蓋後續修復。

## 工程範圍核銷

| 原缺口 | 本輪內容 | 主要驗證 |
|---|---|---|
| S1 持倉語意未承接 | 投組、決策與研究共用實際持倉／觀察池／情境模擬三模式；空持倉不自動轉成自選等權，情境只接受明示正權重，也不改寫實際持倉 | 正式前端契約、三頁切換與重載、快取身分、真實 HTTP、Reader 拒絕與公開資料不變 |
| S2 跨來源更新工作 | 市場、期權、日夜盤工作統一查詢與重試；HTTP 202 表示接受工作；來源完成後仍由原 Pulse writer 提交市場快照 | 真實 SQLite、並行去重、容量、租約、逾時、重新啟動、失敗與沿革 |
| S3 每日研究工作流 | 已提交快照差異、全部證據；整合日線、基本面、法人、新聞、同業、ETF 與既有供應鏈分類；直接持倉關聯、不可覆寫紀錄、事後回顧及完整匯入／匯出 | 唯讀保存來源、個別資料日與缺漏、同交易讀取、逆序回應、摘要不符、匯入衝突及儲存失敗 |
| S4 預警驗證 | 凍結版本、觀測分母、未觸發／未知、1／3／5 日成果、基準、樣本門檻與原始輸入重播 | 品質警示入庫、凍結協定、缺日、未成熟、後補不得改首次成果 |
| S4 回測口徑 | 次日開盤成交、成本、未平倉市價權益與回撤；三個策略消費介面呈現完整前提 | 開盤前不讀當日收盤、跳空、缺值、零交易、未知估值與輸出跳脫 |
| S4 候選變化 | 選股結果依相同條件及排序比較前次成功回應，列出欄位與相對位置變化，保留完整收據 | 缺值、重複代號、範圍截斷、空結果、失敗保留與三尺寸實際下載 |

| S5 研究任務 | 變化、反方、標的、回顧四任務；決策舊入口亦接完整公開父快照、逐次目的地確認及引用隔離，不再截取前 12 筆 | 敵意來源、未知引用、數字及時點、Reader、錯誤父快照、路由變更、串流中斷與儲存失敗；未實際啟動模型 |
| S6 維運與版面 | 分離路由／研究核心／儲存與呈現、CI 與發布加入四份 Chromium 驗收、返回閱讀位置、有界混合負載 | Windows 原生回復、七種尺寸、200% 放大、真觸控、橫向 5×2、慢回應返回、100 次生命週期與模擬恢復 |
| 第三階段焦點缺口 | 關閉 K 線研究回到可見入口；原生對話框開啟時背景全域快捷鍵不攔截 Escape 或 Space | 正式模組及完整瀏覽器外殼，包含更新中心原本誤跳頁的失敗案例 |
| 第三階段首筆影子觀察 | 透過真正每日匯入成功 hook 建立首次紀錄，保留實際取得時點；同日重跑不覆寫 | 正式兩端各 4 筆；2 檔 × 原始／參考價比較，輸入摘要一致 |

研究工作中心的私人紀錄留在目前瀏覽器；市場快照及來源更新沿既有共用服務。研究、筆記與 AI 引用驗證不建立第二套行情發布流程。新的研究工作歷史不刪除；近期清單之外仍可取得完整沿革。既有市場工作的保留範圍會明示。

## 已取得的候選驗收證據

- 完整 Python 回歸執行 907 項：903 項通過、4 項跳過（1 項未啟用的外部即時測試、3 項僅主程式掛接測試）。Windows 原生啟動、發布與回復測試已實跑，沒有列入跳過項目。
- 全部 52 個 JavaScript 自測檔通過，涵蓋三模式、更新、研究紀錄、研究任務、標的整合、候選變化、回測、跨頁生命週期與全域快捷鍵。四份 Chromium 驗收包含研究 14 組／7 種尺寸、手機旋轉五步驟、正式外殼 7 組，以及候選比較三尺寸，列入 Windows／Ubuntu CI 及精確版本發布門檻。
- 真實瀏覽器先重現再修正兩項整合問題：45 秒決策快取不能沿用不同投組模式，更新視窗於 CSS 放大 200% 時必須完整容納。另外以 640×360 CSS 像素與 DPR 2 產生 1280×720 圖，驗證瀏覽器縮放等效重排。觸控拖曳確實移動捲動位置，700 毫秒延遲回應前後返回研究仍保留位置；四盤別固定資料操作均在目標內，但不冒稱真人閱讀速度。
- 非作者覆核修正四項研究正確性問題：來源品質入庫遺失、統計誤用目前全域協定、未來收盤改寫已排定開盤成交，以及組合輸入摘要漏記資格資料。
- 最後契約核對補上全部 14 個公開決策欄位差異、實際模型目的地綁定、獨立伺服器請求收據、頁面離開時同步復原暫存，以及更新中心的私人研究狀態。沒有實際呼叫模型。
- 發布封存使用精確 Git 提交。瀏覽器截圖與 JSON 收據保存在安裝根目錄下的獨立驗收目錄，不納入正式程式內容。
- 隔離候選以既有公開資料副本運行，5 分鐘、4 個並行讀取者，共 3,209 次 HTTP 讀取，失敗 0 次。市場健康與更新狀態第 95 百分位延遲分別為 140／266 毫秒；大型組合計算為 4.172 秒。這是混合負載數據，不代表跨日運行或所有外部來源的可用性。
- 核心快照另做 600 次純讀、失敗 0 次：市場／決策在 4 並行時 p95 為 169.48／122.74 毫秒，符合該固定負載下 300 毫秒目標；20 並行時為 574.72／388.08 毫秒，不能宣稱高並行亦達標。每日研究查詢及大型組合計算與核心快照分開評估。
- 正式每日補齊前，兩端四類資料庫各建立 SQLite 備份，共 8 份，全部通過完整性檢查。兩端每日匯入日期推進至 9/22，首次影子取得時點是實際的 9/23 01:22（臺北），沒有回填成 9/22 當時已觀察。

精確提交、雙平台 CI、正式入口健康、版面截圖、資料保全與發布收據由本輪發布紀錄另行保存；不能以本文的候選驗證取代正式發布後核對。

## 完成範圍的界線

工程可驗證的是計算、儲存、時序、權限、操作及發布行為。下列項目需要另外的證據，不能因程式完成而改稱已完成：

- 尚未發生的前瞻成果，以及足夠樣本的有效性與統計推論。既有已看過的五年歷史不能重新命名為真正未見資料的樣本外。
- 文章作者沒有揭露的箱型／VIDYA 細節。本輪明示工程公式，沒有聲稱完整還原原策略。
- 公司行動期間的實際持有權利、完整含息報酬及委託容量。來源不足時保留未知，不以參考價比值冒充股數轉換。
- 實體 iOS／Android、OS 字型放大、真實模型輸出品質與帳戶費用。本輪手機尺寸使用真實 Chromium 模擬，模型以受控串流驗證，未啟用新付費服務。八小時時鐘間隔與斷網恢復為瀏覽器限定測試，沒有讓主機實際休眠，也未完成跨日壓測。
- 情境風險計算目前只支援可核對的 TW／TWD 台股代號；海外或未知市場輸入保留原文並標示不可計算，不把相同數字代號借當台股。未新增跨幣別投組引擎。

這些界線不是遺漏的實作階段。未來新增資料、實體裝置或模型驗收時，應另記條件與結果；不能覆寫首次研究紀錄美化成果。
