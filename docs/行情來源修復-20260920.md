2026-09-20 依正式服務紀錄追查名稱、產業分類與 NHNL 降級，修復官方端點及上市／上櫃代號在後續查找中的一致性。

## 原因與修正

| 已重現的問題 | 修正後行為 |
|---|---|
| 對 TWSE 要求上櫃 `t187ap05_O`，HTTP 200 卻收到 HTML | 沿用 `台股基本面.py` 的官方資料集定義：上市由 TWSE、上櫃由 TPEx 提供；驗證 MIME、JSON 結構、大小與有效資料列 |
| 部分來源失敗仍把名稱或產業對照標記為當日完整 | 保留既有 RAM／備份資料，失敗退避 60 秒後可重試；所有必要來源成功才標記當日完成 |
| 名稱備份永遠優先，官方改名無法更新 | 當輪成功的官方資料可更新同一代號名稱，保留其餘既有鍵；同輪依既有來源順序決定優先權 |
| 先移除 `.TW` 導致 `6488.TWO` 變成 `6488O` | 修正名稱、選股、投組、籌碼快取、集保、曝險及 WaveDeck 的台股尾碼處理；選股傳給 Yahoo 的 `.TWO` 保持完整 |
| NHNL 對上櫃只使用 `.TW`，有效樣本不足 | 在既有請求預算內嘗試 `.TW`／`.TWO`，暫存成功尾碼；來源失敗、未嘗試與不足樣本皆保留診斷 |
| 非有限值、重複日期或行情時間被當作有效日線 | 只接受有限正值、依日期去重，排除晚於來源宣告交易日的點；仍要求每檔至少 250 根與至少 12 檔有效樣本 |
| 把上櫃對照筆數當上市分類涵蓋；缺分類時成交分母偏小 | 以 TWSE 普通股母體計算分類涵蓋，包含缺漲跌的有效成交額；分類不完整時不產生 HHI／前三大占比，成員清單標示未完整 |

## 驗證與證據邊界

隔離環境實際 GET 已確認舊錯誤端點回傳 HTML；正確上市／上櫃端點分別取得 1,086／892 筆原始資料。正式修正函式在隔離資料目錄取得 1,969 筆名稱與 1,977 筆產業對照。名稱較既有備份增加 `4804`，並依官方來源更新 `1721`、`6949`、`8472`，沒有刪除舊鍵。

固定 12 檔 NHNL 實際比較，修正前 10 檔有效而未達門檻，修正後 12 檔全部有效。此證據只代表該組樣本；不宣稱所有 50 檔或全市場已具備足夠且最新的資料。回應明確提供 `dateBasis=latest_observed_session`、`calculatedAt`、`freshnessVerified=false` 與各來源筆數，計算時間不代替交易日期。

新增回歸涵蓋官方路由、HTTP 200 HTML、無效回應、部分失敗與同日恢復、RAM／備份保留、分類分母、正式選股入口、籌碼 `.TWO` 與裸碼共用快取、投組及其他市場代號消費者。來源回歸已納入精確提交的 Private Web 暫存測試與分享包必要檔案；遠端 CI、最終發布 SHA 與兩端驗收另存交付紀錄。

來源診斷使用既有有界紀錄，不保存憑證。首次探索候選市場時的單次 404 與資料日期過期仍可能發生，須依解析結果、涵蓋範圍與來源日期判讀，不能將 HTTP 成功等同行情完整或最新。
