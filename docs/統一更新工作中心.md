# 統一更新工作中心

市場、選擇權與日夜盤研究共用更新中心。正式市場快照仍由既有 `PulseUpdates` 建置與提交；研究工作不呼叫另一條決策發布路徑。

## 入口與權限

| 入口 | 行為 |
|---|---|
| `GET /updates` | 唯讀聚合既有市場工作與研究工作；不建資料庫、不啟動工作者、不恢復工作。 |
| `POST /updates` | 接受固定類型 `pulse`、`options`、`research` 及有限參數，持久接受後回 HTTP 202。 |
| `POST /updates/retry` | 只接受原工作編號；由原參數建立新工作，保留父工作、根工作與執行次數。 |

Reader 只能查看。閘道須覆寫 `X-ST-Gateway-Role`；後端只允許本機無角色或已驗證的 Owner 提交。未知角色也拒絕。舊期權／日夜盤明確更新入口須接同一協調器，避免同步更新旁路。

`p-` 編號對應原 `pulse_update_jobs_v1` 工作，`r-` 編號對應 `managed_update_jobs_v1`。兩者使用原 `ST_UPDATE_JOBS_DB` 路徑，互不改寫對方的工作表與快照。HTTP 不接受任意函式、資料路徑、供應者網址或模型參數。

## 工作與期限

研究工作使用程序間租約與單一執行者，容量預設 16（包含執行中）；同類型與正規化參數合併。選擇權優先於日夜盤與一般背景工作；等候超過 60 秒者提升順序，避免持續飢餓。市場仍保有原本單一 active 工作與自己既有的執行者，不會被大型研究塞住。

註冊且尚未開始的研究工作可於服務重啟後接續；前次執行中工作標為中斷，不猜測來源已成功。沒有可重建函式的一般背景工作保留中斷收據，由原排程重新提出。工作終態儲存失敗只重試收據，不重跑已完成的來源函式。研究工作歷史全數保留；即時清單顯示最近 100 筆終態與全部執行中／等待工作，較早歷史透過 `GET /updates/archive` 及工作中心匯出連結取得。市場工作維持原有保留規則，匯出會明示範圍。

非合作來源超時後仍占用執行槽，介面明示「已超時仍在等待底層結束」；底層返回後才標為 `timed_out`，不宣稱已強制停止網路 I/O。合作式 guard 在期權歷史／磁碟／記憶體快取，以及日夜盤快取提交前檢查期限，逾時的結果不提交。重新執行不能與同一工作仍在等待的來源並行。

來源更新完成後，先等待完成前已開始的市場工作結束，再交由原市場發布者建立新快照；結果列出關聯的市場工作編號。研究來源完成與正式市場快照已提交是兩個不同狀態，介面各自呈現。來源不足或保留舊快取的降級回應不得算成功。

市場重試沿革使用原市場工作的持久 `reason` 欄位記錄父識別，不新增市場 writer。超出既有歷史保留範圍時明示沿革不完整，不補造早期根工作。

## 介面

工作中心顯示類型、階段、工作識別、臺北時間、狀態、錯誤、執行次數、重試沿革及關聯的正式快照。前端訂閱共用一個讀取請求與輪詢計時器；隱藏分頁或最後一個訂閱離開會停止瀏覽器讀取。失敗保留前次清單，HTTP 202 僅表示接受工作，不表示來源或發布已完成。

對話框支援鍵盤、Escape、回復可見的開啟按鈕及背景原生焦點隔離。窄版單欄，寬版雙欄；長識別與錯誤完整換行，不裁掉資訊。輪詢刷新保留重試按鈕焦點。

`UpdateJobs.wait(jobId, {signal, timeoutMs, onProgress})` 使用同一份訂閱跟隨工作到終態，預設也等待研究結果所關聯的市場發布工作。取消與有界等待結束都會釋放自己的訂閱和計時器，不取消伺服器工作；即使工作在開始等待前已完成，也不留下訂閱。`followMarket:false` 僅供明確只需來源完成的呼叫者使用。

## 離線驗證與接線

`tests/test_統一更新中心.py` 使用真實暫存 SQLite 與工作者驗證並行去重、容量、優先順序、老化、重啟、程序租約、逾時占槽、重試沿革、終態儲存失敗，以及來源期限後不得提交。原期權、日夜盤與 H5 佇列測試保持通過。`tests/更新工作_selftest.js` 執行正式前端 store，驗證共享輪詢、錯誤保留、重複提交、權限、隱藏分頁與 100 次訂閱／離頁。

服務啟動先建立原 Pulse worker，再呼叫 `configure_updates(pulse)`；關閉時停止 `coordinator().queue`。正式 `Handler` 加入 `UpdateRoutesMixin`、三條固定路由及閘道允許清單；前端依序載入 `core/更新工作_v5.js` 與 `ui/更新工作中心.js`，入口呼叫 `UpdateCenter.open(可見按鈕)`。完整 HTTP、版面與正式發布驗收由整合流程另外記錄，不以本文件代替。
