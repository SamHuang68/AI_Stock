# ETF 個股資訊消失：8D 復原與防再發報告

日期：2026-09-29。責任歸屬：本次及上一輪修正的 Codex 主控。

**結論：上一輪修正造成未經使用者同意的功能退化。** 原始歷史資料沒有刪除，但個股觀察卡的 ETF 入口、加減碼與 STATS 明細被條件判斷隱藏。這仍是使用者可見功能的移除，不能以「防止誤報」當成合理化理由。

| D2 定義問題 | 觸發版本 `8afbe938c6e4`。`/etf-delta` 有 127 檔、9,364 筆持股，但 59 檔來源日期相同、25 檔格式改變、43 檔缺前期；異動陣列全部為空。實際圖表頁所有台股 ETF 明細徽章數為 0。個股點選後原可查看的資訊消失。 |

| D4 根因分析 | 發生原因：把「不可作本期訊號」錯誤映射成 `available=false`；觀察卡依它隱藏徽章，STATS 又依異動列為空回傳空字串。API 只提供前十大，導致非前十大個股無法以持股明細補回。逃逸原因：測試把不可比較必須 unavailable 寫成通過條件，只測 ETF 管理視窗及防誤報，沒有走觀察卡 → 浮窗 → STATS 的原功能路徑。系統原因：變更契約前沒有列明受影響消費端與使用者可見資訊，亦未取得任何刪減功能的同意。主控以測試數量替代功能保留驗收，上一份 8D 的完成結論範圍過大。 |
| D5 永久修正 | 分離明細可用性與訊號有效性；同一比較函式處理本期及歷史，新增完整持股與最近可比較紀錄。歷史紀錄逐檔標示兩期來源日期，只供閱讀，不回灌本期 `new/removed/changed`、計數、`chgSum` 或 POS 共識。浮窗及 STATS 共用明細呈現函式。 |
| D6 驗證有效性 | 本機真實資料：台積電 44 檔持股／10 筆最近可比較異動，聯發科 46 檔／8 筆。85 檔 ETF 找到最近可比較期，42 檔尚無；本期訊號仍為 0，103 份歷史快照雜湊不變。完整回歸、實際瀏覽器操作及正式部署結果於本報告末尾列出。 |
| D7 防再發 | 回歸測試直接執行真正的 `renderWl()` 與浮窗程式，驗證待比較、無異動、未載入仍有入口；驗證非前十大、跨市場隔離、歷史期間、歷史無異動、快取失效、毀損舊快照及本期訊號隔離。明細呈現共用一處，避免 STATS／浮窗再分歧。往後涉及 `available`、異動陣列或訊號門檻的改動，必須核對所有消費端與原有操作；需刪減資訊時先明列內容並取得同意。 |
| D8 結案與責任 | 對未通知便讓功能消失負責，不把責任歸給資料供應商或使用者操作。功能恢復以真實點選、內容、日期與部署版本共同驗收；資料仍不可比較的限制，留在畫面明示，不再透過隱藏入口處理。 |
