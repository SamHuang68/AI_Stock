# 選股候選的位置與欄位變化

選股頁沿既有 `/screen3` 結果加入前後比較，不另建排名引擎。完成掃描後可展開「候選位置與欄位變化」，查看相同篩選條件的前次成功回應與這次回應；變更篩選條件不直接混比，切回原條件時仍能找到本頁先前的同條件收據。

目前排序欄位與方向同時套用於兩份回應，再列出各標的位置與欄位變化。排序值未知、資料未完整或代號重複時，名次保持不可比較。原始回傳位置明示不是推薦順序；排序值沒有改變但位置改變時，指出候選集合、其他候選值或同值順序可能改變，不編造公司事件原因。

本次新增與本次未見只代表回傳集合變化。兩次掃描的完成範圍、截斷、缺少資料與各欄位日期均可能不同，因此不能直接推定新增標的才開始符合條件，或未見標的已被淘汰。完整條件、來源欄位、研究資料日期及涵蓋摘要可展開查看；取得時間使用明確時區的 ISO 時間，不替代行情日、財報期別或公告日。

本頁開啟期間保留全部成功回應，包括空結果。掃描失敗保留前次結果；切換排序不發出新查詢，也不覆寫原收據。可下載完整 JSON 備份及當下比較。重新載入頁面後需重新建立比較，介面會明示此保留範圍；這不是永久研究帳本。若要永久保存假說及事後回顧，使用既有研究工作台的紀錄流程。

驗證涵蓋相同條件與不同條件、排序值改變與未改變、未知與零值、重複代號、空結果、截斷、掃描失敗、對外副本隔離、來源文字跳脫及完整收據下載。原生 Chromium 另外在 Windows 尺寸、手機直式與橫式操作兩次掃描、切換排序、展開比較及下載，確認結果容器可捲動且沒有頁面水平溢位。
