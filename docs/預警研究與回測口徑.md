# 預警研究與回測口徑

本文件對應全面升級計畫第五章。新增能力維持影子研究，不改買進分數、決策權限或通知策略。

## 前瞻預警分母

`warning-observation-study/2026-09-v1` 以規則引擎版本、生命週期政策版本、訊號識別與市場日期的首次快照作為觀測單位。同一天後續盤中轉移仍在既有事件帳本保存；不能把每日首次快照的漏報率解讀為所有盤中預警的漏報率。

每筆觀測保存當時完整 Context、Pulse、記憶體資料、純規則輸出、實際狀態、加權指數起點、可取得時間、官方交易日曆版本與五個未來目標日。無警報也保存，資料不足保存未知。三個新表分別凍結協定、觀測與成果，沿原發布 writer 的 SQLite 交易寫入；重試與重啟不改首次觀測。研究寫入失敗回滾研究 savepoint 並回傳可見的 unavailable，不掩蓋既有預警狀態。

研究協定在註冊前固定：可用領域至少三個，資料完整度與新鮮度必須已知且大於零。起點至未來 1、3、5 個官方交易日的收盤路徑，同方向最大變動達 2% 定義為事件。基準為同一起點加權指數當時漲跌方向。這是工程版事件研究，沒有交易價格、收益承諾或作者策略還原意涵。

第一個目標交易日已開始便拒絕補登前瞻樣本。目標日臺灣時間 18:00 後才成熟；只有日期的舊日歷史在當天仍無法證明是正式收盤。帶時區的來源時間必須晚於目標日 13:30 且不晚於解析時鐘。指定目標日缺失不跳至下一筆。首次到期發布即凍結成熟或未知成果，後續補值、修訂不重寫成果。

結果依版本、訊號與方向分層，列出已成熟、未成熟、未知、已到期尚待 writer 解析及日曆可證明的未觀測日期。漏報只計已完整觀測事件；全市場漏報率固定為未知。基準比較使用同一成熟事件配對母體，缺基準不當零。原始每日樣本與最早日起依序選取的非重疊樣本數分列；至少 20 個相應分母才顯示比率，此門檻不代表統計顯著。門檻到達日數不稱為相對基準領先時間，最大有利／不利變動只代表收盤路徑。

舊 `signal_trials` 沒有無警報日的完整分母，也未凍結官方預期日期，保留歷史而不回填。其成果現在依 engine/policy 版本分開，混合版本總覽不顯示合併勝率；缺版本保持缺版本標記。舊欄位 `materialMoveLeadSessions` 為相容性保留，新增 `eventArrivalSessions` 與明確限制說明。

## 主控接線

既有發布 writer 呼叫 `process_context` 時增加：

```python
research_calendar = early_warning.warning_research.load_calendar(datastore.DB_PATH)
early_warning.process_context(..., research_calendar=research_calendar)
```

`load_calendar(path)` 以 `mode=ro` 與同一讀取交易查 `market_sessions`、`calendar_years`。不存在、空日曆、未知來源或跨界資料保持 unknown，不建表、不補資料、不呼叫外部日曆服務。

`process_context` 與 `performance` 回傳 `researchValidation`。`performance` 本身為唯讀且不建立不存在的 DB，另提供 `researchObservations` 最近 n 筆識別與凍結摘要，完整原始輸入由重播函式讀取。`replay_observation(observation_id, path)` 只讀回傳凍結證據並重播純規則；先檢查輸入摘要與 engine/policy 版本，不具歷史執行碼時回傳 version_unavailable。狀態機歷史保存為原快照，不冒充已重新推演。

## 簡易回測

`backtest-next-open/2026-09-v1` 保留 `run`、`runLS`、`scanStrategies` 呼叫形式，改為收盤訊號後下一根輸入棒開盤進場。無有效價格、零量、品質問題或一價棒無法證實成交時取消該次進場；不跳到之後的有價日期。停利、停損、持有期限、退出訊號均由收盤確認，再於下一棒開盤成交。退出受阻時保留部位及待退出狀態。

參數 `feeRate` 是單邊費率，`taxRate` 只收賣出側，`slippage` 使買價較高、賣價較低。成本依實際成交金額計算，不是固定從報酬扣兩次百分比。UI 預設 0.25% 單邊費用只是情境，不代表市場費率；核心為相容性預設零成本，但回傳完整假設。`tp`、`sl`、`maxBars` 設零可以停用。

權益每棒按收盤市價計算，包括持有期浮動損益；末筆未平倉不強制成交、不計成已平倉勝率。持有期無有效估值使完整回撤未知。已知公司行動或未核對的重大價格斷點後，持有權利未知，後續價格恢復也不虛構已知收益。空頭極端損失可超過本金，保留負權益並停止新增部位；借券可得性與費用尚未建模。

每棒夏普使用逐棒權益變動；樣本不足或缺估值回傳 null。年化只使用明確的 `barsPerYear` 假設，預設 252 棒，不保證輸入一定是日線。輸入未核對完整官方日曆、公司行動與流動性，因此即使計算完整仍屬同樣本策略探索，不能提升為有效策略證據。

獨立資金配置的 `portfolio` 合成器傳遞未知值，不將 null 轉零；它不共用資金池、不模擬再平衡。資金受限的多標的成交模擬須使用另行定義的研究模組。
