# 台股基本面資料口徑

個股基本面、三合一選股、估值承接研究及代號庫財報欄位，共用 `server/台股基本面.py` 的資料集清單與解析方式。

- 月營收先讀證交所及櫃買中心官方總表。總表缺少某家公司時，沿用公開資訊觀測站逐家公司尋找最近四個完整月份；同時涵蓋國內與外國公司表。
- 每筆營收保留實際期別、來源及金額單位。其他公司已有新月份，不代表該公司也已公布；採用前一期時，畫面明示最近可得月份。不同月份的金額與年增率不混補。
- 綜合損益表涵蓋上市、上櫃的一般業、金控業、金融業、保險業、證券期貨業及異業，共十二個官方資料集。
- 財報顯示年度及季別，金額為該年度截至該季累計。原始金額保留新臺幣千元，畫面換算為元／萬／億；基本每股盈餘本來就是元，不乘一千。
- 金融與異業直接列 EPS、本期稅後損益及可得的母公司損益。未經驗證的跨業三率與一般業評分不套用；資料不足時也不評分。本期綜合損益不替代本期淨利。
- 數值零是有效資料；空字串、布林值、NaN、無限值不是有效數值。來源暫時失敗五分鐘後可重試，不以整天空表快取；前端缺漏或前一期資料一分鐘後可重新查詢。

2026-09-13 診斷案例：元大金（2885）與凱基金（2883）未列入當時的八月月營收總表，但七月 MOPS 表有資料，金控業第二季累計財報也有 EPS。原流程只讀一般業損益，且回補找到任一非空總表即停止，導致兩項資料同時消失。這是來源選擇與逐股期別確認的缺漏。

官方規格：[證交所 OpenAPI](https://openapi.twse.com.tw/)、[櫃買中心 OpenAPI](https://www.tpex.org.tw/openapi/)。

回歸測試：`tests/test_台股基本面.py`、`tests/台股基本面顯示_selftest.js`；既有選股與研究測試持續檢查共用欄位。
