# AI 報告與副駕修復

## 問題與修正

- 報告生成曾再次呼叫會被導覽橋接包裝的入口。延遲開啟會移除正在顯示結果的面板；現在建立面板與導覽入口分開，生成期間重開也會保留同一份內容。
- 副駕收到 HTTP 標頭後就清空提示，模型推理期間看起來沒有反應。現在保留等待文字、顯示秒數與請求識別碼，收到正文才更新內容。
- 報告與副駕阻止重複送出，提供取消接收；關閉面板後的舊回應不會覆蓋新結果。取消接收不保證模型立刻停止，介面會明確說明。
- 本機與 Private Web 共用程序間執行鎖，忙碌時明確退回，避免同時堆疊多份推理。沿用既有 `daemon_lock`，程序結束亦會釋放。
- 本機報告、副駕、Pulse 摘要共用串流客戶端，要求 SSE 完成事件。錯誤、空正文、輸出截斷與未收到完成確認均不可當成成功，也不可覆寫上次報告。
- 預設報告使用既有本機模型，不需雲端金鑰；使用者仍可主動選擇既有 Claude 雲端路徑。模型沒有自動切換或付費後援。
- 個股快照須同時核對代號及 `Market.of` 市場；切股尚未完成時不引用舊價格。K 棒時間轉為臺北時間，缺少大盤或新聞時要求明說資料不足。
- 報告 Markdown 先轉義 HTML；既有雲端報告的空內容與輸出上限也會顯示未完成。私人閘道的報告／短評沿用 AI 等待上限。

## 驗證

前端 `tests/ai_panels_selftest.js` 使用正式面板及導覽橋接模組，涵蓋延遲重建、重複送出、取消、舊回應、UTF-8 切割、錯誤回覆、完成確認、報告保存、HTML 轉義，以及台股、櫃買指數、美股與日股的資料歸屬。

後端 `tests/test_ai_local.py` 與 `tests/test_ai_routes_stream.py` 涵蓋共用鎖、串流完成／失敗、LM Studio 與 Ollama 提早結束、雲端空報告及資料邊界。雲端測試全部使用模擬回應，沒有付費模型呼叫。

發布檢查納入新串流測試與前端面板測試。正式執行證據保存在本輪工作目錄的 `scratch`，不將使用者行情、持倉、金鑰或模型正文納入 Git。

## 執行限制

本機模型回覆速度取決於載入、推理與當時資源狀態；本次修復不承諾即時產出。雲端報告仍須有效的既有金鑰與供應商可用額度。真實雲端與外部深度模型未在本次驗收呼叫，前端與失敗路徑以模擬測試確認。
