# 估值承接研究

從「選股」選擇「估值承接」，或輸入四位數臺股代號開啟「個股估值研究」。原本估值視窗也有「設定估值假設與分批承接」入口。

此流程先縮小研究範圍，再由使用者設定可持續獲利、承接價及退出價，最後觀察價格結構與含費稅的部位情境。正本益比只是本輪估值研究的先決條件，並未證明獲利未來仍可維持。

## 範圍與假設

- 預設官方本益比大於零且不高於 30 倍，上限可修改，例如 40 倍；沒有 20 倍下限。缺值、零、負值均不入選。
- 3529 力旺、6643 M31 是預設另案名單，並非完整矽智財產業名單。其他公司的高本益比同樣受目前設定的上限限制。
- 個股研究可標為一般獲利企業、AI 供應鏈／景氣循環、IP／另案估值。分類不自動提高倍數；單股詳情即使被篩選排除仍可查看。
- 可持續 EPS、適用期間、估值理由與倍數區間均由使用者填寫。區間起始值 20～30 倍可修改，不是通用合理估值結論。
- 假設估值下緣＝可持續 EPS × 倍數下緣；上緣同理。未填承接價或退出價時，分別使用估值下緣與上緣；明確填入無效值時拒絕計算。
- 依假設 EPS 計算的本益比與官方本益比分開。既有固定 EPS 股價區間參照不再被描述為歷年實際本益比或可持續盈餘預測。

## 觀察定義

| 項目 | 定義與缺值處理 |
| --- | --- |
| 官方本益比 | 重用 TWSE／TPEx 官方資料查表，保留來源明載日期；未附日期時明示缺少日期。 |
| 月營收 | 最近可取得的月營收年增、月增及累計年增，保留公告期別；單一期別不能證明獲利趨勢。 |
| 價格 | 已完成交易日收盤；臺北時間 13:30 前不採當日日線。 |
| 100 日回撤 | 最新完成日收盤相對近 100 個交易日最高收盤價的百分比；不足 100 日不提供。 |
| 前 20 日區間 | 最新完成日之前 20 個交易日的最高價及最低價，排除當根；不是另行確認的整理型態。 |
| 接近上緣 | 價格未越過區間上緣且距上緣不超過 2%。 |
| 帶量越過 | 收盤越過上緣，當日成交量除以前 20 個完整交易日均量至少為 1.5；缺量或量不足不確認。 |
| 投信 5 日 | 與最近五個完成價格交易日對齊。只接受每股記錄明載的來源交易日；依來源日期去重，不以日檔檔名當交易日證明。 |

既有籌碼快照未保存來源交易日時，最新淨買、五日合計與連買均保持未知。畫面顯示觀測日數與缺項，不把缺值當零，也不建立不可比較的全市場買超排名。

掃描摘要列出官方可取得的初始清單、估值通過數、股價完成數、各排除原因及缺資料數。最多顯示前 80 筆，超出時明示截斷。排序依區間位置及距上緣距離，不是報酬預測；可以用產業條件縮小清單。

## 分批成本與紀錄

每批由價格與正整數股數計算。每批買進費用取比例費率與最低費用的較高者；退出試算包含賣出費用與交易稅。預設買賣費率各 0.1425%、賣出交易稅 0.3%、每筆最低費用 20 元，均為可修改的試算設定，應依實際券商與交易類型調整。未設定總投入上限時不假設為零；超出上限保留負的剩餘金額並顯示錯誤。

「依前批下跌 10% 新增價格」只建立下一批價格，不代填股數、不送出委託。第一批空白時採已設定的承接價。這個功能不寫入實際持倉。

正式假設、修訂及觀察紀錄保存在目前瀏覽器。未完成輸入以獨立草稿保存，關閉後可恢復；「還原已儲存假設」可放棄草稿。另一分頁已更新的假設不會被舊分頁背景刷新覆蓋。本機與私有網站屬不同瀏覽器來源，個人研究紀錄不會自動同步。

觀察只在儲存或重新整理時記錄。相同觀察不重複；修改個股假設、本益比上限或另案排除設定會重建比較基準，不冒充市場趨勢變化。無效、未來或倒退的價格／估值日期不進歷史。這個版本沒有新增背景通知或自動交易。

## 驗證

新增後端測試覆蓋估值範圍、來源別名、資料日期、部分資料、截斷及突破當日量能；純計算測試覆蓋分批成本、最低費用、資金上限與缺值；儲存測試覆蓋草稿、版本、日期與多分頁競態。私有網站沿用既有驗證與角色權限，新估值詳情僅允許讀取。
