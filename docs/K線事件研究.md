# K 線事件研究與官方日線更新

圖表頁「選股策略 → K 線事件」提供 K 線、成交量與黃色事件點，以及相同型態的後續 1、3、5、10 個交易日表現。

## 歷史時間軸

- 研究期間可選近 30 個交易日、3 個月、6 個月、1 年、3 年、5 年、10 年、完整歷史及自訂期間；預設近 3 年。月／年期間依截至日往前推算曆月，月底與閏日會調整至該月最後一天。
- 自訂期間填入開始日期，可搭配截至日期；截至日期留空使用最新已完成交易日。所有預設期間也能搭配過去的截至日期。
- 圖表、事件清單及統計使用同一個研究期間。開始日前最多 20 個交易日僅供暖機，不計入期間樣本；截至日以後的資料不參與報酬。
- 圖表每段可選 30、60 或 120 日，以「最早／上一段／下一段／最新」、時間軸滑桿或跳至日期瀏覽。休市日期會定位到之後第一個區間內日期；圖表分段不改變統計。
- 事件清單由新到舊，每頁 50 個事件日。點選事件會將圖表移到該日期並顯示判定依據。
- HTML 報告不依賴 JavaScript，包含所選期間全部 K 線（每段最多 120 日）、全部事件、目前選定報酬期數的統計及資料品質，並非僅匯出目前圖表或事件頁。

「完整歷史」指資料庫現存日線範圍，不代表已涵蓋上市以來全部交易日。畫面同時列出資料庫起訖與本次研究起訖；交易日曆建立以前的日線仍可瀏覽，但會標示尚未核對並排除事件判定。已知交易日缺資料時保留缺口，避免後續第 N 日變成第 N 筆資料。

API：`GET /kline-events?sym=2330&range=all`；自訂期間例如 `?sym=2330&range=custom&start=2025-01-01&asOf=2025-12-31`。`range` 接受 `30d`、`3m`、`6m`、`1y`、`3y`、`5y`、`10y`、`all`、`custom`；省略時為 `3y`。回傳所選期間完整 `candles`／`events`，以及 `availableStart`、`availableEnd`、`timelineDays`、`warmupDays` 等範圍資訊。

## 更新方式

系統的「日線快取」由使用者明確選定標的後更新，不自動回補整份觀察清單，也沒有安裝新排程。一般歷史更新使用既有 Yahoo 日線；官方研究每次限一個上市四碼股票或 ETF、1／3／5 年，按月份邊界回補。目前未支援上櫃公司行動涵蓋。官方來源尚未公布或身分、月份、欄位不符時拒絕寫入並顯示錯誤。

`POST /daily-cache/refresh` 接受 `symbols:[{symbol,market}]`、`range:1mo|3mo|1y|3y|5y` 與 `kind:history|official`。一般歷史最多 5 個標的；來源請求使用明確起訖時間。`GET /daily-cache/status` 顯示來源、期間、完成數及錯誤；`POST /daily-cache/cancel` 接受 `jobId`。私有 gateway 只允許既有 owner 執行或查看更新工作，reader 可讀研究結果。

每次工作上限 10 分鐘、240 次來源請求，請求間隔至少 1.2 秒，同時只允許一個選定更新工作。取消後停止下一次請求；進行中的 HTTP 有逾時限制，回應後及寫入鎖內、每列與提交前再檢查取消。官方月份失敗或取消整批回滾，較早完成月份保留。快取重用依成功來源查詢期間紀錄；首尾兩筆價格不代表中間完整，查詢涵蓋也不保證供應商缺日已補齊。

「僅預算本機快取」只讀 `/bars` 並執行現有 JavaScript Worker。快取鍵包含完整 Worker 程式與 OHLCV；公式或輸入不同就不重用，沒有新增 Python 技術分數。`GET /bars` 現為 cache-only，空資料明示 `missing`，不暗中抓取五年資料；TW／US 使用各自市場分區。

手動 CLI `python server/台股日線.py --database <路徑>` 預設只更新最近完整交易日；18:00 前取前一交易日，明確指定 `--start YYYY-MM-DD` 最多 31 日。`--seed-research` 為手動研究用途。CLI 只處理指定資料庫，不自動操作另一個 Private Web 資料庫。

上市使用 TWSE MI_INDEX，上櫃使用 TPEx dailyQuotes，涵蓋普通股、特別股、ETF 與 TDR；不包含權證、個別債券或興櫃。成交量為股。交易日曆同時核對年度開休市表與 TWSE FMTQIK 實際成交日，保留颱風等臨時休市。每個市場及日期原子提交，核對回應日期、欄位、重複代號與資料筆數，並記錄來源雜湊。錯誤不會偽裝成更新成功。

`/bars` 回傳最新日期核對狀態；筆數不代表資料新鮮度。開高低收缺值與未知成交量保留 null，零成交量仍為零。體檢與同市場樣本池遇無效 OHLCV 會保留日期缺口、切段重新暖機。投組報酬依交易所日期對齊；不改 VaR、相關性、集中度或風險上限公式。

`market.db` schema v3 新增品質、官方原始觀測、公司行動、日曆及來源查詢涵蓋表。既有庫升級前使用 SQLite backup 建立 `market.db.pre-quality-v3.bak`，不覆蓋已存在備份；遇更高版本拒絕降版寫入。備份可先還原到獨立路徑核對版本與原價，再停服務執行必要回復。

同市場、標的與交易日的首次價格保留。官方價格相同時沿用原時間戳；不同時把新版本存到 `official_daily_observations`，原品質保留來源雜湊並標示差異，該日排除研究。Yahoo 修訂沿用 `bar_source_revisions`，不得覆寫既有日線。舊來源資料不因歷史回填自動成為已核對官方資料。

## 判定與報酬

- 長紅／長黑：收盤相對開盤大於等於 +1.5%／小於等於 −1.5%。
- 十字線：實體絕對值除以開盤小於等於 0.2%。
- 成交量異常：當日成交股數嚴格大於前 20 個交易日均量的 1.5 倍。
- 突破／跌破：收盤嚴格高於／低於前 20 個交易日最高／最低價；比較區間不含當日。
- 原始收盤價報酬不含股息、稅費；跨除權息、減資、面額變更或重大價格斷點的區間排除。缺日不壓縮、缺報酬不補零，各期樣本成熟度分開計算。
- 統計提供樣本數、平均、中位數、上漲比例、中間 50% 分布、相同條件基準及非重疊樣本；少於 30 筆提示小樣本，不推論顯著性。

實際歷史與公司行動涵蓋以資料庫為準，沒有預設宣稱已建立三年資料。公司行動只有三個既有 TWSE 來源完整成功才延長涵蓋；未完成時明示不可判定。研究回補沿用已觀測、符合實際交易日的月份。

截至日期限制事件與可觀測報酬，使用目前核對後的歷史資料，並非重建當時發布版本。沒有 point-in-time 財報、完整還原價格與下市全集，不聲稱消除存活者偏差。此事件描述與 `signal_stats_pool.py` 的訊號研究、`backtest_v3.js` 的下一可成交 bar 與費用／滑價回測各自維持契約；上漲比例不是技術分數。黃色點表示歷史事件，不是買賣訊號或價格預測。
