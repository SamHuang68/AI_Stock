# K 線事件研究與官方日線更新

圖表頁「選股策略 → K 線事件」提供 K 線、成交量與黃色事件點，以及相同型態的後續 1、3、5、10 個交易日表現。

## 歷史時間軸

- 研究期間可選近 30 個交易日、3 個月、6 個月、1 年、3 年、5 年、10 年、完整歷史及自訂期間；預設近 3 年。月／年期間依截至日往前推算曆月，月底與閏日會調整至該月最後一天。
- 自訂期間填入開始日期，可搭配截至日期；截至日期留空使用最新已完成交易日。所有預設期間也能搭配過去的截至日期。
- 圖表、事件清單及統計使用同一個研究期間。開始日前最多 20 個交易日僅供暖機，不計入期間樣本；截至日以後的資料不參與報酬。
- 圖表每段可選 30、60 或 120 日，以「最早／上一段／下一段／最新」、時間軸滑桿或跳至日期瀏覽。休市日期會定位到之後第一個區間內日期；圖表分段不改變統計。
- 事件清單由新到舊，每頁 50 個事件日。點選事件會將圖表移到該日期並顯示判定依據。
- HTML 報告不依賴 JavaScript，包含所選期間全部 K 線（每段最多 120 日）、全部事件、目前選定報酬期數的統計及資料品質，並非僅匯出目前圖表或事件頁。

「完整歷史」指資料庫現存日線範圍，不代表已涵蓋上市以來全部交易日。畫面同時列出資料庫起訖與本次研究起訖；交易日曆建立以前的日線仍可瀏覽，但會標示尚未核對並排除事件判定。已知交易日缺資料時保留缺口，避免後續第 N 日變成第 N 筆資料。

API：`GET /kline-events?sym=2330&range=all`；自訂期間例如 `?sym=2330&range=custom&start=2025-01-01&asOf=2025-12-31`。`range` 接受 `30d`、`3m`、`6m`、`1y`、`3y`、`5y`、`10y`、`all`、`custom`；省略時為 `3y`。回傳所選期間完整 `candles`／`events`，以及 `availableStart`、`availableEnd`、`timelineDays`、`warmupDays` 等範圍資訊。

## 更新方式

平日早晨簡報排程在臺北時間 07:30 先執行 `scripts/更新台股日線.ps1`。腳本從 `data/stock_python.path` 或 `ST_PYTHON` 取得 Python，更新本機與 Private Web 的 `market.db`。18:00 前以之前已完成交易日為目標，遇週末及休市往前找；官方尚未公布時保留失敗紀錄，下次沿用已提交日期並補齊缺口。

上市使用 TWSE MI_INDEX，上櫃使用 TPEx dailyQuotes，涵蓋普通股、特別股、ETF 與 TDR；不包含權證、個別債券或興櫃。成交量為股。交易日曆同時核對年度開休市表與 TWSE FMTQIK 實際成交日，保留颱風等臨時休市。每個市場及日期原子提交，核對回應日期、欄位、重複代號與資料筆數，並記錄來源雜湊。錯誤不會偽裝成更新成功。

`/bars` 回傳最新日期核對狀態；筆數不再代表資料新鮮度。開高低收與成交量缺失保留空值與品質原因；舊來源資料不因歷史回填而變成官方資料。官方日線以市場、代號、交易日期為準，Yahoo 不能覆寫同日資料。

## 判定與報酬

- 長紅／長黑：收盤相對開盤大於等於 +1.5%／小於等於 −1.5%。
- 十字線：實體絕對值除以開盤小於等於 0.2%。
- 成交量異常：當日成交股數嚴格大於前 20 個交易日均量的 1.5 倍。
- 突破／跌破：收盤嚴格高於／低於前 20 個交易日最高／最低價；比較區間不含當日。
- 原始收盤價報酬不含股息、稅費；跨除權息、減資、面額變更或重大價格斷點的區間排除。缺日不壓縮、缺報酬不補零，各期樣本成熟度分開計算。
- 統計提供樣本數、平均、中位數、上漲比例、中間 50% 分布、相同條件基準及非重疊樣本；少於 30 筆提示小樣本，不推論顯著性。

首次已建立台積電 2330 的三年 TWSE 日線及除權息／減資／面額變更涵蓋區間。其他標的可看官方近期日線；公司行動尚未完整核對時明確顯示不可判定。研究回補可執行 `scripts/更新台股日線.ps1 -SeedResearch`，會沿用已核對完成月份。

截至日期限制事件與可觀測報酬，使用目前核對後的歷史資料，並非重建當時發布版本。黃色點表示值得觀察的歷史事件，不是買賣訊號或價格預測。
