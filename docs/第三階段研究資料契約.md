# 第三階段研究資料契約

## HTTP 與 Python 入口

| 請求 | Python 呼叫 | 行為 |
| --- | --- | --- |
| `GET /breakout-research?sym=2330&range=3y&asOf=2026-09-30` | `突破觀察.report(db, symbol, as_of=None, now=None, *, period='3y', start_date=None, include_execution=True)` | 唯讀一致快照；缺資料回傳 `missingData` |
| `GET /breakout-shadow?sym=2330` | `突破影子紀錄.list_records(db, symbol, *, limit=100)` | 唯讀首次紀錄及修訂筆數 |
| `POST /breakout-shadow` | 伺服器重算 `report` 後呼叫 `freeze(db, result, *, price_basis='raw', observed_at=None)` | 首次附加，修訂另列；不接受客戶端計算結果 |

期間支援 `30d/3m/6m/1y/3y/5y/10y/all/custom`；自訂期間另傳 `start`。`asOf` 不可超過今天，研究自動截到最新已完成市場交易日。POST JSON 與 GET 採相同 `sym/range/asOf/start`，另加 `priceBasis: raw | official_reference`。寫入與影子讀取沿用整合路由的擁有者授權及同源保護，不新增權限。

`report` 回傳 `sym/asOf/status/freshness/range/historyStart/historyEnd/timelineDays/warmupDays/missingData/candles/research`；資料庫不存在或必要結構不可查時 `research=null`。`research` 包含 `version/rules/latest/stats/rows/execution/adjusted`；`adjusted` 有自己的訊號與成交研究，成交列仍採原價。`freeze.code` 為 `recorded/unchanged`，`status` 是中文狀態，`added` 是本次是否新增首次紀錄。

## 共用純函式與資料接合

`load_dataset(conn, symbol, cutoff)` 不建表、不寫入、不抓來源，供突破與投組研究共用。回傳：

- `rows`：日期遞增、缺市場交易日保留空列；OHLCV、`date/time/source/sourceDate/sourceHash/retrievedAt/priceBasis/issues`。
- `session_dates`：已核對市場日期。年度 `closed/opened` 重建預期日，已保存 `session_months` 實際交易日校正臨時休市，拒絕未核對來源的市場列。
- `calendar_years/action_days/action_coverage/adjustments/missingData`。精確分割資料只增加「不可跨行動計原價損益」日期，不製造參考價因子。
- `action_coverage_kind` 為 `stock/etf`；ETF 來源範圍必須明示 ETF／分割／四類，普通股票涵蓋不予接納。`action_coverage_evidence` 明示它是已保存範圍聲明，不能當成四類官方參考價完整收據。

既有 `bar_quality.price_basis='原始價格'` 明確映射為 `unadjusted`。未有品質資料不能猜測，`sourceDate` 不等於行情日期時封鎖；有效 OHLC 邊界、正成交量、官方 TWSE／TPEX 來源、停牌／終止交易亦獨立核對。

`build_research(rows, *, calendar_years, action_days, action_coverage, sample_start=0, adjustments=None)` 是純訊號引擎。輸入時間軸不得省略交易日；回傳逐列 `eligible/conditions/signals/reason/metrics`，統計與最新輸入摘要。

`execution_outcome(rows, signal_index, horizon, *, side_cost=.0025, symbol=None, calendar_years=None, action_days=None, action_coverage=None, session_dates=None)` 回傳 `status=mature/immature/excluded`、`positionStatus=closed/open/not_entered/excluded`、訊號與成交日期／原價、`grossReturn/netReturn` 小數報酬。若提供 `session_dates`，缺列會補成明示缺資料，不跳到下一有價列。純引擎沒有自動抓取或判定未知公司行動的能力，呼叫端須提供核對資訊。

`net_return(entry_price, exit_price, side_cost)` 回傳小數；`build_execution` 統計列的 `gross/baseNet/stressNet` 則是百分比，差額為百分點。不得混用。SCENARIOS 固定 `{gross:0, baseNet:.0025, stressNet:.005}`。

## 已保存官方參考價格式

讀取既有 `action_price_coverage` 與 `action_price_evidence`。本輪不自動建表或產生證據；缺任一表即明示不足。這兩張表由明示的官方證據匯入流程維護，讀取報告不能建立它們。

`action_price_coverage` 欄位為 `market/symbol/start_date/end_date/parser_version/sources_json`。每張收據須有 `route/url/sourceHash/retrievedAt/stat/start/end`，覆蓋 `TWT49U/TWTAUU/TWTB8U/TWTCAU` 四類路由的完整區間；查無事件亦需正式空結果收據，不能由事件列表為空推定完整涵蓋。

`action_price_evidence` 欄位為 `market/symbol/session_date/kind/previous_close/reference_price/factor/status/reason/source_hash/source_url/retrieved_at/parser_version/payload_json`。`payload_json` 保留 `fields/row/request:{start,end}`，標的、生效日、事件種類、路由與原始欄位互相核對。解析版本固定 `twse-reference-ratio-v1`。

僅接納已核對的純除息及 ETF 分割參考價；同日多因子、其他權利／減資、來源不明、前收不匹配或重大斷點未解釋皆保守排除。參考因子為 Decimal `reference_price / previous_close`，其用途是歷史訊號窗口換算，不是股數分割比率或股息再投資。

## 保存與版本

`breakout_observations` 主鍵為 `symbol/session_date/rules_version`；首次保存 `observed_at/input_digest/evidence`。修訂表 `breakout_observation_revisions` 另以新摘要去重。`record_daily(db, *, now=None, observed_at=None, check=...)` 僅掃描既有 `action_coverage` 股票，日更成功後執行，無資料抓取、無歷史補造。

訊號版本為 `breakout-observation-v2`／`breakout-observation-adjusted-v2`；成交版本為 `breakout-execution-v2`。版本變動保留 v1 原有觀察。開始研究前固定的切分為訓練截至 2023-12-31、測試自 2024-01-01，切分邊界交易另列，不以測試區間調參。
