# 第三階段：官方參考價調整比較

本階段解決 2330 與 0050 的長期研究資料涵蓋，沿用官方日線、交易日曆及市場交易日。原始成交價、既有六種事件、第一階段原始價格研究及其影子紀錄保留；新增獨立調整比較模式，不增加買進分數。

## 官方證據與價格語意

- [除權除息計算結果](https://wwwc.twse.com.tw/zh/announcement/ex-right/twt49u.html) 提供除權息前收盤價、除權息參考價及權／息類型。
- [ETF 分割恢復買賣參考價格](https://www.twse.com.tw/zh/announcement/split/twtcau.html) 提供停止買賣前收盤價及恢復買賣參考價；是獨立於面額變更的官方來源。
- 2026-09-22 已讀取四個公司行動接口的 2025 年資料，原始回應及雜湊存於 `scratch/第三階段驗證/官方來源`。0050 分割日為 2025-06-18，來源欄位為分割前 188.65、恢復買賣參考價 47.16。參考價已捨入，兩者比值不能當作精確股數轉換比率。

比較價格因子採官方完整參考價除以官方前收盤價，屬本專案明確定義的比較基準，不宣稱為官方發布的還原日線或總報酬。僅放行已核對的純除息與 ETF 分割；除權、減資、面額變更、同日多個事件或未知欄位持續排除。每一因子需保留原始列、欄名、查詢網址、回應雜湊、擷取時間、解析版本及涵蓋證據，並與當地官方原始前收盤核對。

每個觀察日以當日為價格基準。歷史日 d 的比較 OHLC 只乘入 d 之後至觀察日之間已生效的因子；未來事件不能影響過去條件。前一日首次事件判斷使用前一日自己的基準。不調整成交量，不覆寫 bars，也不把擷取時間冒充事件當年的發布時間。

跨事件比較仍需完整日線、來源、價格基準、成交量與交易日曆。缺因子、前收盤不一致、因子無效、同日複合事件或不可解釋價格斷點均維持不可判定。原始價格的重大斷點只有在官方因子可解釋時改檢查調整後殘餘變化；其他異常仍排除。

## 版本與讀取契約

- 原 `research` 維持 `breakout-observation-v1`；新增 `research.adjusted`，規則版本為 `breakout-observation-adjusted-v1`。
- 新模式沿用同一批原始日線，僅以 `candles[].adjustedResearch` 保存各日新比較結果。新模式成交計算將該結果傳給既有成交引擎，開盤與收盤一律使用原始價格，跨公司行動的持有期仍排除。
- 個股、0050、公司行動及因子資料須在同一個唯讀 SQLite 交易快照內取得。無新資料表的舊資料庫可回應明確未建立狀態，不可因 GET 而建表。
- 新模式摘要含比較基準、觀察日期、相關因子與輸入摘要；只計入實際比較窗口。既有影子紀錄不覆寫，新模式依不同規則版本另行留存。
- UI 提供兩種比較模式並標明資料前提；HTML 匯出保留原始與調整兩種研究的完整明細，不因畫面選擇而省略。

## 回補與驗收

先在本機 SQLite 驗證副本回補 2330、0050 的近五年；月份只在完整且有效時跳過，已知缺日維持缺口，停止交易不壓縮市場日。回補完成度區分官方回應取得與有效可判定資料。成功後才透過同一管線匯入本機及 Private Web，各自備份、各自保留其他標的與設定。

驗收須包含：未來事件隔離、每觀察日基準、複合／缺漏／矛盾因子拒絕、原始成交價不變、跨事件損益排除、同日配對公平性、唯讀一致快照、摘要修訂與影子紀錄不可覆寫，以及官方實際回補後的可判定天數。有效樣本增加不等於策略優勢。
