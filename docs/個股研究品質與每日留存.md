# 個股研究品質與每日留存

本輪依使用者「全部執行」授權，完成營收來源完整度、專業報告更正、資料品質、研究更新狀態、每日事件留存及除權息／成本敏感度。沿用既有行情資料庫與訊號引擎，不變更原本研究的候選門檻。

## 契約

- 個股卡的品質列分別呈現日線、籌碼、大盤情境、合併統計。依本機指數已知交易日判斷落後；沒有交易日證據時標示未知，不把週末或假日直接算成缺資料。產生時間與行情截止日分開顯示。品質不足不刪除既有資料，但指出受影響的判讀。
- 研究維護使用既有工作佇列；一個工作編號串起來源補齊、資料檢查、離線統計、每日留存與完成／失敗。介面預設只使用本機資料，不暗中下載、呼叫模型或推播。只有當次勾選明示 Yahoo／TWSE、傳輸內容及費用範圍的同意框，才執行既有來源補齊命令；部分失敗仍保留缺漏並標示部分完成。
- 每日留存使用獨立帳本，固定記錄啟用之後、當日已收盤的全部事件。凍結原始輸入及版本，去重且不可覆寫。後續結果由首次取得的日線追加；依指數交易日對齊，缺日保留待補。歷史研究與候選前瞻協定保持原樣。
- 還原資料由既有 Yahoo 行情解析路徑取得，存在同一行情資料庫的獨立快照表，不覆寫原始 OHLC。缺少還原值、對不上原價或日期不連續時不假定調整係數為一。
- 補取範圍涵蓋本機所有股票，不只研究門檻以上的股票。期間依各股票最早既有日線指定，拒收來源自動降為月線的結果；最多四路下載、循序寫入，依交易日期避免重複。已下載與可納入比較分開計數，完整缺日與價差保留在專業模式。收盤前的當日快照不得阻擋收盤後補取。
- 敏感度比較原價與還原價的事件集合，以及共同事件的次日收盤起算報酬。成本情境為往返總成本 0／20／50／100 基點，各半套於進出價格；這些是研究假設，不代表任何券商實際收費。樣本不足 20 筆不顯示比例與報酬。
- 還原序列是目前來源的事後重編價格，不宣稱當年點時可知；資料供應商可能修訂。新增分析不修改既有 `no_candidate`，不作交易執行。
- 每日留存只讀本機資料，可持續執行的前提是 Stock Terminal 主機運行且啟用本機留存。未開機、沒有當日日線或市場基準缺日，都保留缺漏，不補造歷史觀察。
