# 架構與功能審查修復

本次修正對應 2026-09-19 審查的 F01 至 F10，延續模組化單體架構，保留既有行情來源與使用者資料。

| 問題 | 修正行為 | 主要回歸證據 |
|---|---|---|
| F01 來源過期卻顯示新資料 | 以行情觀測時間、市場寬度日期及既有交易日曆判斷；讀取快取時重新檢查效期，過期時取消部位範圍 | `test_決策資料品質.py` |
| F02 缺資料誤當零風險 | 保留原始持倉分母，回傳涵蓋率與不足原因；共同樣本不足時波動與 VaR 為空值，實際投組不得產生部位範圍 | `test_決策資料品質.py`、`投組缺值與效期呈現_selftest.js` |
| F03 跨標的晚到報價 | 綁定標的、市場、載入序號、LIVE 啟用週期及請求序號，拒收來源時間倒退 | `LIVE報價一致性_selftest.js` |
| F04 決策請求逆序 | 相同輸入合併請求，不同輸入建立新一代；舊回應不能發布或清除新請求 | `非同步資料一致性_selftest.js` |
| F05 後端發布回退 | 以更新開始時間接納版本；發布鎖涵蓋預警、最新狀態與歷史副作用 | `test_決策資料品質.py` |
| F06 台美股產業混入快取 | 回應寫回請求開始時的市場，背景市場完成不重繪目前市場 | `非同步資料一致性_selftest.js` |
| F07 面板重複啟動 | Shell／AppKernel 統一管理啟動與清理，取消舊導航的延遲工作；補齊總覽、投組、廣度、新聞、盤後、決策、熱力圖焦點及因子頁已確認的晚到回應 | `非同步資料一致性_selftest.js`、`面板非同步生命週期_selftest.js`、`市場廣度生命週期_selftest.js`、`因子頁生命週期_selftest.js` |
| F08 決策修訂未保存 | 完整輸入、計算結果與規則版本參與指紋；不同選擇權修訂留下不同歷史 | `test_決策資料品質.py` |
| F09 發布中斷無法回復 | 候選目錄核驗後切換，保存前版與切換紀錄；啟動或健康檢查失敗時回復並保留最新執行期資料 | `test_發布完整性.py`、`test_sync_private_web.py` |
| F10 受測內容可漂移 | 暫存、重用與發布都驗證逐檔 SHA-256；舊版缺少雜湊的暫存包必須重建 | `test_發布完整性.py` |

`data/`、`logs/` 為執行期資料邊界。發布時只補缺少的公開種子，不覆寫既有資料；回復舊程式仍保留目前資料。SHA-256 用於驗證受測內容一致性，不是數位簽章，也不宣稱能抵抗同時修改內容及資訊檔的本機管理者。

新增測試透過受控 Promise、執行緒、真實渲染函式、暫存 SQLite 與檔案故障注入驗證行為。既有全部 Python 與 JavaScript 檢查仍為整合門檻。精確提交的遠端 CI、服務版本與版面證據另記錄於本次交付驗證紀錄，不能以此文件代替執行證據。

本機整合驗證：Python 3.12 共 597 項，593 項通過、4 項依既有條件略過；JavaScript 33 組全部通過；Python 編譯、建置順序與 HTML 建置通過。Windows HTTP 標頭拒絕測試改以空本文避免連線重設干擾，仍明確驗證 413／415；本文大小與解析邊界的既有測試保留。
