# 選股基本面與整合契約

本次在既有技術分析及市場資料契約上補回可驗證的需求。技術分數仍為 0–100，體檢獨立；事件研究的樣本勝率不取代技術分數。

## 三合一選股與排序

`POST /screen3` 的結果固定包含月營收年增、本益比、殖利率、投信及外資連續天數，不以使用者是否設定篩選條件決定是否補欄位。有效的零保留；缺值在未啟用該條件時保留，在啟用條件後不能當成零而通過。

估值採官方資料。未附來源日明示未知；已附但格式無效、互相衝突或超前的來源日會使該數據不可用。月營收期別與來源出表日分開，不能用抓取日冒充資料日。ETF 不套公司估值及營收條件。

籌碼只讀既有快取與官方交易日曆，不因進入選股而補抓全市場歷史。來源日去重，缺日、衝突與未知日期不能跨接；連續觀察未找到終點時，正值呈現下限、負值呈現上限，並保留完整性說明。無法證明符合門檻時不納入。

一般結果的 11 個欄位可由表頭或工具列排序。缺值置底，同值保留原順序；重設恢復本次查詢順序，排序不重新查詢。範圍僅限本次已載入的最多 80 檔，並非全市場重新排名。尚未部署的研究模型沒有新增排名欄位。新查詢及離頁會取消前次接收，晚到結果不能覆蓋新查詢。

## 台股基本面

共用 `server/台股基本面.py`，來源為 [證交所 OpenAPI](https://openapi.twse.com.tw/) 與 [櫃買中心 OpenAPI](https://www.tpex.org.tw/openapi/)。上市與上櫃各自涵蓋一般業、金控、金融、保險、證券期貨與異業的財報資料集。只有一般業適用既有三率；金融等業別列 EPS、稅後及母公司業主淨利，不以綜合損益替代淨利，不套一般業評分。

金額保留新臺幣千元及倍率 1000，顯示時轉換一次；EPS 為元。年度、季別、出表日必須合法，季報期末不得超前或晚於出表日。官方彙總欄位未附單季／累計起訖時，期間基礎標為未知，不由季別推定累計、不重建單季、不年化 EPS。月營收的「累計」則只使用來源明確標示的累計欄位。

月營收總表不足時，沿用公開資訊觀測站的上市／上櫃、國內／外國公司分表，逐股查最近四個完整月份。來源表頭期別及千元單位必須與請求一致。相同期別才比較完整度，不以舊月份 YoY 補進新月份。完整結果最多快取 300 秒，缺值或不完整結果最多 60 秒；來源失敗不整天保存為空表。

畫面分開顯示月營收與財報的期別、來源及出表日。較舊月份明示可能尚未申報或來源暫缺。這些是目前取得的公開資料，沒有歷史當時可得版本，不宣稱消除前視或存活者偏差。ETF 原因推導亦保留各期證據及限制，只能描述可能線索，不能宣稱知道基金實際動機。

## 焦點、AI 與私有存取

焦點掃描共用完成後才起算的短期快取，相同市場同時請求合併為一份工作。`GET /focus?mkt=TW&cacheOnly=1` 只讀已完成的有效結果；即使附 `refresh=1` 也不觸發掃描或等待正在執行的工作。沒有快取時回明確空狀態。市場脈動的焦點卡獨立標示完成時間，不混成市場快照的一部分。

AI 串流以明確完成事件或提供者完成證據判定成功；只有 EOF 不算成功。截斷、逾時、取消與錯誤不保存為完成回應。共用客戶端用於既有副駕駛、市場脈動及決策介面，保留證據約束，不新增模型、憑證或對外 HTTP 入口。

更新工作、私有 gateway 及發布完整性另見相應文件。所有正式存取仍受既有 Tailscale、角色與同來源限制。唯讀瀏覽不能提交更新工作。
