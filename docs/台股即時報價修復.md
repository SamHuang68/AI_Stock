# 台股即時報價來源修復

問題影響共用台股報價流程，包含上市、上櫃與 ETF。MIS 回傳最外層 `z` 為缺值時，最新真實成交仍可能存在 `trade.z` 與 `trade.t`。舊程式忽略這組資料並退回 Yahoo；開盤初期 Yahoo 可能仍回傳上一交易日，造成主圖、自選與持倉顯示昨日價格及漲跌。

四個個股入口 `/twquote`、`/twquote-batch`、`/quote`、`/quote-batch` 現在共用官方成交解析。仍只採成交價，不以委買、委賣或開盤價推估。成交時間與成交量觀測時間分開保留；盤中日期不符或時間不明時，不提供冒充當日的價格與漲跌，備援仍揭露來源及時間。

主圖各檢視範圍的現價與自選共用報價；持倉不再以選中個股的舊 K 線收盤覆寫較新的報價。前端以成交時間拒絕倒退回應。缺值顯示待更新，歷史持倉價格保留但不當成今日漲跌；心跳顯示成交來源時間。

回歸涵蓋舊版 `z`、新版 `trade.z`、缺失與非法成交、未來時間、昨日 Yahoo 備援、成交量單位、四個 HTTP 入口、非台股交易時區、自選／持倉與報價時間倒退。真實行情探測與瀏覽器紀錄保存在工作目錄 `scratch`，不納入公開版本。

這是官方 MIS 輪詢行情，不是券商逐筆推送。主圖約 3 秒、自選約 5 秒輪詢；上游發布、網路延遲與成交頻率仍會影響更新時間。歷史分 K 仍來自既有歷史來源，這次修正不宣稱整段分 K 已具備券商等級即時性。
