📊 專案概覽

本機運行的 Bloomberg-style 個股研究終端機。零雲端、零外部 Python 套件、純 stdlib 即可跑。整合即時 K 線、16 項技術指標、台股主動式 ETF 持股追蹤、倉位管理、規則化訊號引擎、AI 形態辨識，以及多檔個股的多訊號共識評分系統。

⚙️技術架構
Python ThreadingHTTPServer + ThreadPoolExecutor(32) + LRU Cache(20K) + HTTP/1.1 keep-alive。前端純 vanilla JS + lightweight-charts CDN。
🎯核心優勢
所有運算本地完成，零追蹤、零雲端依賴。LocalStorage 保存倉位與觀察清單，重灌不掉。完全屬於你。
🚀效能
Core Ultra 9 285H 主機上一鍵切股 < 200ms（含指標 worker 計算）。LRU 快取讓重複查詢 0ms。

🤖 AI 形態辨識 v2.2

規則式偵測 8 種經典 K 線形態 — 沒用機器學習（黑盒、不可解釋），全部基於專業技術分析的固定規則。每個形態都有清楚的數學定義、量度目標、歷史驗證的勝率。

為什麼不用 AI / ML？機器學習形態辨識的問題：(1) 訓練資料偏差難避免；(2) 黑盒判斷無法解釋為何說「這是雙頂」；(3) 過擬合風險高。規則式方法雖然死板，但每個結論都能追溯到具體規則 — 這對「股市小白學技術分析」反而是優勢。
📈多/空頭結構5⭐
HH+HL（高點墊高、低點也墊高）= 多頭趨勢；LH+LL = 空頭趨勢。趨勢追蹤勝率最高的訊號。
🔻雙頂雙底（M/W 形態）4⭐
兩個相近高/低點 + 頸線突破。量度目標 = 頸線往反方向延伸雙頂高度。
👤頭肩頂/底5⭐
3 個峰中間最高（左肩/頭/右肩），雙肩高度相近。最經典反轉形態。
↔️箱型整理3⭐
近 30 日於窄區間整理（振幅 < 12%）。等方向選擇。
🚀區間突破4⭐
從箱型突破上下緣 + 量能判斷有效性（> 1.5x 均量為有效）。
✨黃金/死亡交叉4⭐
SMA20 × SMA60 近 5 日交叉。中線經典訊號（注意有滯後）。
☕杯柄形態4⭐
U 型 + 把手回檔 < 杯深一半。William O'Neil 經典突破策略。
◢三角收斂3⭐
高點下移 + 低點上移 = 收斂中性形態。等突破方向。
使用方式：點線型上方「🤖 形態」按鈕跳出 modal 列出當前所有形態（含描述、原理、量度目標、行動建議、可靠性星級）。長按 ≥ 0.5 秒則直接在 K 線上疊出所有關鍵價位（左肩/頭/右肩/頸線/目標等）。

🛠 專業工具列 v2.1 +

時間段按鈕右側的 5 個專業工具。每個都是真正幫助決策的功能，不是花俏裝飾。

📊vs 大盤對照必備
疊上 ^TWII（台股加權）或 ^GSPC（S&P 500）的歸一化線。看個股相對大盤的真實表現。TSMC 漲 2% 但大盤漲 3% 其實是相對弱勢。
用法：點擊「vs 大盤」按鈕。橘色線 = 大盤；個股 vs 橘線 = alpha。
📍POC 量價分布v2.1
將 K 線歷史價格切 24 個區間，畫出最大量價位（紫色虛線）。POC 是真正的支撐/壓力位 — 成交量最密集 = 套牢最多人。
用法：點擊「POC」按鈕。價格在 POC 附近震盪是正常；明顯偏離可能回歸。
▶Replay 重播練功
隱藏「未來」K 線，用滑桿一根根放出來。模擬「當下你會怎麼決策」。練盤感、練心理、檢驗自己會不會看錯。
用法：點擊「▶ Replay」進入。◀ ▶ 按鈕逐根前進，滑桿任意拖。✕ 退出。
🤖形態辨識v2.2
短按跳出 modal 列出當前偵測到的所有形態；長按疊到 K 線上。詳見「AI 形態辨識」章節。
用法：點擊「🤖 形態」短按看清單，長按 ≥ 0.5 秒切換 K 線疊圖。
⚪LIVE 即時報價v2.2
啟用後右上角浮現 LIVE 面板，每 30 秒自動輪詢 Yahoo v8 chart 1m bar。顯示最新價、漲跌、日內高低、量、市場狀態（盤前/中/後/休）。
用法：點擊「⚪ LIVE」啟用。台股延遲 ~15 min（Yahoo 免費限制）。
🎨手繪支撐壓力線v2.1
在 K 線圖上右鍵點擊任何位置 → 跳出選單 → 加金線（壓力）/ 綠線（支撐）/ 紅線（停損）。每檔股票各自存。
用法：圖上右鍵 → 選顏色加線 / 「✕ 清除全部線」一次清。
📊策略歷史回測v2.1
用當前個股 5 年資料模擬「策略觸發 → 隔日開盤進場 → 20 日後出場」。輸出交易次數、勝率、平均報酬、最大盈虧。
用法：WATCH → 切「🔧 單一策略」模式 → 表單底部「📊 回測這個策略」。

為什麼預設只啟用主動式 10 檔？MoneyDJ 抓取每檔約 1-3 秒。全部勾起來會跑 60+ 檔 × 2-3 秒 = 2-3 分鐘。所以預設只勾真正會看持股 delta 的「主動式 ETF」（每日揭露完整持股 → 真正有 delta 可看）。其他分類大多被動 ETF，持股變動慢，需要時再勾。

新增 API endpoints

GET  /etf-catalog          回傳 etf_catalog.json 完整內容
POST /etf-catalog          更新 catalog (整檔覆寫 + 自動備份 .bak)
POST /etf-tracker/run      背景 thread 觸發 etf_delta_tracker.py
GET  /etf-tracker/status   查詢 tracker 狀態 {running, lastDuration, lastReturnCode, lastOutput}
注意：tracker 觸發只能在你本機 server 上跑（必須有 Python + 能連 MoneyDJ）。沙箱排程不能用（網路擋）。Claude scheduled-tasks 必須關掉，只依賴 Windows Task Scheduler。

🚀 典型使用流程

三個常見情境的完整流程，從觀察到進場到管理。

情境 1：建立 2330 觀察 → 觸發進場 → 倉位管理
1
頂部輸入 2330 按 GO，自動載入線型 + 16 指標
2
右側點 WATCH 分頁 → 選「📋 套用劇本」 → 經典回檔買進 → 加入觀察
3
右上角 🔔 通知 啟用瀏覽器推播
4
數天後 — 推播觸發 + 通知中心紅色徽章 → 點 🎯 訊號跳到 2330
5
確認共識評分為 🟢 強多 +3 → 切 POS 分頁建倉，填進場價、張數、停利停損
6
投組風險面板自動算 — 確認單股佔比 < 30% 不超標
情境 2：判斷個股反轉風險（用形態辨識）
1
載入個股，點 🤖 形態 按鈕跳出 modal
2
看到「🔻 雙頂 - 已跌破頸線確認反轉」⭐⭐⭐⭐
3
長按 🤖 把雙頂 + 頸線 + 量度目標疊到 K 線上視覺化
4
如果有持倉 → 切 POS，依「建議行動」執行
情境 3：策略上線前的回測驗證
1
載入要驗證的個股
2
WATCH → 切「🔧 單一策略」 → 選策略（如「突破 N 日新高」）
3
調整參數（如 N=20, 量倍 1.5x）
4
點「📊 回測這個策略」 → 看勝率、平均報酬、最大盈虧
5
勝率 ≥ 55% & 平均報酬正向 → 加入觀察清單實戰
