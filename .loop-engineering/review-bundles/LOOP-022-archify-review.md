## Diagram contracts

### Decision evidence lineage

- Observed market inputs feed the existing normalization and scoring paths.
- One canonical DecisionContext is published by DecisionData; MarketData and DecisionData retain their single-writer contracts.
- Decision Center and the floating Consensus Attention radar are projections, not writers.
- Evidence Ledger preserves source, timestamp/session, basis, and raw audit value.
- The Archify document explains the contract only; it neither fetches nor displays live data.

### Private Web trust and AI execution

- Browser traffic enters the authenticated Private Web gateway before the ST origin.
- Credentials and sessions stay in the existing gateway boundary.
- AI requests execute on the EVO-T1 host, not on the phone or remote browser.
- Fast local AI and deeper AI availability are reported separately and may degrade independently.
- Advisory AI has no direct trading, market refresh, or canonical-state authority.

### Private Web release gate

- Release input must be an exact Git ref and pass required-file, build, test, privacy, and artifact-integrity gates.
- Promotion preserves production data and logs.
- The six specifications, six HTML files, manifest, and validator are required release files.
- Visual receipts and raw internal review receipts are deliberately excluded from release/share packages.

### Pulse refresh and degradation

- One refresh coordinates core, extras, and side inputs with bounded deadlines and a short cache.
- Missing optional sources degrade explicitly rather than creating competing writers.
- The final snapshot becomes one DecisionContext/MarketData publication used by all projections.
- Static diagrams never join this refresh sequence.

### Responsive shell ownership

- The shell owns viewport routing and scroll boundaries.
- Portrait chart mode pages the whole chart workspace; ordinary panels retain their single shell scroll owner.
- Touch landscape keeps the Pulse expert 5+5 layout; the rule is not generalized to unrelated panels.
- Diagnostics report overflow but do not mutate layout automatically.

### Signal Passport lifecycle

- Eight documented states: observe, watchlist, pending, direction-confirmed, active, evidence-conflict, direction-invalidated, and recovery-observe. No undocumented `EXPIRED` API state is invented.
- `strength` is evidence strength, never future probability.
- Signals remain shadow-only and have no transaction authority.
- Prospective checks occur after first registration at 1/3/5 trading days; rates are withheld until the minimum sample threshold is met.

## HTTP and authentication boundary

Only authenticated standalone paths under `/assets/docs/archify/` ending in `.html` receive the diagram document policy. Both origin and gateway enforce:

- `default-src 'none'`
- `script-src 'unsafe-inline'`
- `style-src 'unsafe-inline'`
- `img-src data: blob:`
- `media-src blob:`
- `font-src 'self' data:`
- `connect-src 'none'`
- `worker-src 'none'`
- `frame-src 'none'`
- `object-src 'none'`
- `base-uri 'none'`
- `form-action 'none'`
- `frame-ancestors 'none'`
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: no-referrer`

The gateway removes a potentially broader upstream policy before setting this policy. It also suppresses the normal Private Web profile injection for diagrams. Unauthenticated GET/HEAD browser navigation with `Accept: text/html` receives a login redirect that preserves the full requested path and query as one encoded `next` value. API-style requests and writes remain 401 and never become browser redirects.

Archify HTML contains passive Google Fonts links generated by the viewer. They are allowed by the static artifact scanner but blocked when served by the above HTTP CSP. Direct `file://` viewing is portable but does not receive ST response headers; the manifest states this caveat rather than claiming zero possible external requests in that mode.
