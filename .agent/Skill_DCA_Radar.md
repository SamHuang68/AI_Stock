# Skill: 00631L & 2330 DCA Tactical Radar
**Description:** 每天自動監控 00631L (元大台灣50正2) 與 2330.TW (台積電) 的技術指標，尋找高勝率的低接建倉點，避免情緒化交易。

**Trigger (觸發條件):** 每週一至週五，台股收盤後（下午 14:30）自動執行。

**Task Flow (執行流程):**
1. **數據獲取 (Python 理科生任務)**：
   - 使用 `yfinance` 抓取 `00631L.TW` 與 `2330.TW` 過去 60 天的日 K 線資料（收盤價、最高、最低）。
2. **量化指標計算**：
   - 請 Agent 自動導入 `pandas` 與 `pandas_ta` (或手寫邏輯)，計算出這兩檔標的的：
     a) **KD 指標** (9日)
     b) **RSI 指標** (14日)
     c) **月線乖離率** (與 20 MA 的距離)
3. **建立觸發邏輯 (DCA 訊號判定)**：
   - **綠燈訊號 (強烈建議買進)**：當 K 值 < 20 或 RSI < 30，且月線乖離率為負值（超賣區）。
   - **黃燈訊號 (可小額試單)**：當 K 值 < 35 且大盤處於連續兩日下跌。
   - **紅燈訊號 (禁止動用現金)**：上述條件皆未滿足，指標處於高檔。
4. **本地 AI 語意解讀 (文科生任務)**：
   - 將算好的 KD、RSI 數字與當日收盤價，透過 API 送給本機端的 `gemma2:9b` (或您設定的 Ollama 模型)。
   - **System Prompt 強制規定**：「你是一位冷靜的量化避險基金經理人，請根據提供的 KD 與 RSI 數字，用繁體中文給出一段 100 字以內的點評，告訴投資人現在是該『耐心等待』還是『動用現金分批建倉』。」
5. **輸出與警報**：
   - 產出一份終端機報告。如果有出現「綠燈訊號」，請在終端機發出系統提示音，並在畫面上用醒目的紅色/綠色字體標示：「⚠️ 絕佳建倉時機出現，建議可動用部分現金部位！」
